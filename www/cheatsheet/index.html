🦥 webserv — cheatsheet

./webserv configurationFiles/08_config_pour_eval.conf

Basique

→ 200 OK

curl -v http://localhost:8080/index.html

→ 404 Not Found

curl -v http://localhost:8080/nope.html

→ 405 Method Not Allowed

curl -v http://localhost:8080/upload

→ 301 Moved Permanently

curl -v http://localhost:8080/old-page

→ 200 ou 505

curl -v --http1.0 http://localhost:8080/

POST / Upload

→ 415 Unsupported Media Type

curl -v -X POST http://localhost:8080/upload \
  -H "Content-Type: text/plain" \
  -d "hello world"

→ 200 ou 201

echo "test content" > test.txt
curl -v -X POST http://localhost:8080/upload \
  -F "file=@test.txt;type=application/octet-stream"

→ 413 Payload Too Large

python3 -c "print('A' * 100000)" > big.txt
curl -v -X POST http://localhost:8080/upload \
  -F "file=@big.txt;type=application/octet-stream"

→ 200 ou 204

curl -v -X DELETE http://localhost:8080/upload/test.txt

→ 404 Not Found

curl -v -X DELETE http://localhost:8080/upload/inexistant.txt

Erreurs

→ 400 Bad Request

curl -v -X POST http://localhost:8080/upload \
  -H "Content-Length: -1" \
  -d "data"

CGI

→ 200 + output du script

curl -v http://localhost:8080/cgi-bin/index.py

→ 200 + output du script

curl -v -X POST http://localhost:8080/cgi-bin/index.py \
  -H "Content-Type: text/plain" \
  -d "param=valeur"

→ 504 Gateway Timeout

curl -v http://localhost:8080/cgi-bin/infinite_loop.py

Requêtes glr

→ 400 ou timeout, pas de crash

echo "" | nc localhost 8080

→ timeout propre, pas de crash

echo -e "GET / HTTP/1.1\r\nHost: localhost" | nc localhost 8080

→ 400, pas de path traversal

printf "GET /\x00../../etc/passwd HTTP/1.1\r\nHost: localhost\r\n\r\n" | nc localhost 8080

→ 400 ou 431, pas de crash

python3 -c "
import socket
s = socket.socket()
s.connect(('localhost', 8080))
s.send(b'GET / HTTP/1.1\r\nHost: localhost\r\nX-Big: ' + b'A'*100000 + b'\r\n\r\n')
print(s.recv(4096))
"

Stress

→ Availability 100%, Failed 0

siege -c 10 -t 30s http://localhost:8080/index.html

→ Availability 100%, Failed 0

siege -c 100 -t 60s http://localhost:8080/index.html

→ pas de crash, toutes les requêtes traitées

python3 -c "
import requests, threading

def spam():
    for i in range(100):
        requests.get('http://127.0.0.1:8080/')

threads = [threading.Thread(target=spam) for _ in range(50)]
for t in threads: t.start()
for t in threads: t.join()
"
